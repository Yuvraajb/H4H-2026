# GuideVR Demo Script

Placeholder demo script for GuideVR demonstrations.

## Demo Flow

### 1. Introduction (30 seconds)
- Explain the problem: bystanders freeze in emergencies
- Show the solution: GuideVR spatial assistant
- Highlight the social good angle

### 2. Live Mode Demo (2-3 minutes)
- Start a live session
- Simulate an emergency scenario (e.g., "Someone collapsed")
- Show AI guidance with:
  - Voice responses
  - Visual instructions (images)
  - Urgency indicators
  - Step-by-step guidance

### 3. Training Mode Demo (2 minutes)
- Switch to training mode
- Select a scenario (e.g., "CPR")
- Practice the scenario
- Show scoring and feedback

### 4. Report Generation (30 seconds)
- End the session
- Generate and show the PDF report
- Highlight the handoff value for professionals

### 5. Q&A (remaining time)

## Key Talking Points

- **Accessibility**: Works on shared devices, no training required
- **Adaptive**: Works for ANY emergency scenario, not hardcoded
- **Professional Handoff**: Auto-generated reports save time
- **Real-time**: Voice + visual guidance in the moment
